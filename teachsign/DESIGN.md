# TeachSign — Arah Desain

## Identitas

Materi kursus buatan guru, bukan template SaaS. Terasa seperti lembar fotokopi dan papan tulis kelas: tenang, jelas, sedikit kasar di tepinya.

## Palet

| Token | Nilai | Pakai |
| --- | --- | --- |
| `--bg` | `#faf7f2` | latar halaman (kertas hangat) |
| `--surface` | `#fffdf9` | kartu, panel |
| `--ink` | `#1a1a1a` | teks utama |
| `--muted` | `#6b6259` | teks sekunder |
| `--line` | `#e3dcd2` | garis tipis |
| `--line-strong` | `#cfc5b8` | garis tegas |
| `--primary` | `#b8442a` | aksen tunggal (bata) |
| `--danger` | `#a02c1c` | galat |
| `--warning` | `#8a5a12` | peringatan |
| `--sidebar` | `#201d19` | panel samping (tinta gelap) |

Aksen hanya satu. Tidak ada gradien. Tidak ada warna kedua untuk dekorasi.

## Tipografi

- Judul: **Newsreader** (serif), bobot 600. Rapat, sedikit editorial.
- Badan: **Inter**, bobot 400/500. Netral dan mudah dibaca.
- Huruf besar semua hanya untuk label kecil, jarak lebar.

## Bentuk

- Radius `4px`. Sudut hampir tegak, seperti kertas dipotong.
- Batas (`border: 1px solid var(--line)`) menggantikan bayangan. Bayangan hanya untuk lapisan mengambang (modal), dan tetap tipis.
- Tidak ada ikon dekoratif, emoji, atau gradien. Label teks lebih dulu.

## Nada Tulisan

- Kalimat langsung, tanpa pembuka dan penutup.
- Tanpa tanda pisah em (`—`), tanpa "selamat datang", tanpa "yuk", tanpa embel-embel.
- Angka dan istilah teknis apa adanya.
